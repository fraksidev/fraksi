# Puppet artwork

This demo deliberately uses temporary, programmatically rendered silhouettes.
They are not presented as culturally authoritative shadow-puppet artwork.

To replace them, preserve the part IDs and measured local pivots in
`src/rig/puppetManifest.ts`, then replace each temporary part path with licensed
or commissioned flat artwork. Record the artist, culture/tradition, license,
source, and any required attribution here before distribution.
